# FebMod-Hypixel-Addon

### What is this?
* This is the official hypixel addon for FebMod
* It is coded using the FebMod API from https://github.com/FebEmpire/febmod/tree/dev/src/main/kotlin/com/feb/mod/api

### How do i use this?
* Download the jar file and place it in febmod/addons in your minecraft folder
* You can find the instructions on how to set up FebMod on https://github.com/FebEmpire/febmod or https://febempire.github.io/febempire-website/documentation/febmod/febmodgettingstarted.html
